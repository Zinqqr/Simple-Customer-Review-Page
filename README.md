## Social Proof Section – Frontend Mentor Challenge

## Short Description
This project is a solution to the Social Proof Section challenge from Frontend Mentor. The goal was to build a responsive section showcasing customer reviews, ratings, and testimonials in an engaging and visually appealing way.

The design emphasizes social proof — a proven marketing strategy where real customer feedback helps build trust and credibility. This layout combines rating cards with short testimonial quotes to communicate positive user experiences.

## Features
Fully responsive design for mobile, tablet, and desktop screens.

Clean, semantic HTML5 structure.

CSS Flexbox and Grid for layout management.

Hover and focus states for interactive elements.

Pixel-perfect alignment with the provided design.

## Tools & Technologies
HTML5

CSS3 (Flexbox & Grid)

Google Fonts

Frontend Mentor assets
